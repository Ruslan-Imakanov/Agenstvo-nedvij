## Правила
- Чистые HTML/CSS/JS без сборки. Одна страница `public/index.html`, логика — `public/app.js` (ES-модуль).
  На hoster.kz главную собирает `hoster/index.php`: шаблон (`index.html`) + правки владельца из кабинета `/admin/` — README («Кабинет администратора»).
- Контакты компании, трёх специалистов и партнёров — только в `public/site.config.js`; в разметке телефоны/почта компании
  помечены `data-co-phone` / `data-co-email`, блоки специалистов — `data-spec="valuation|replan|deals"`,
  блок партнёров — `data-partners`. Общий номер должен быть виден в шапке на любой ширине экрана.
- Направления: `valuation` (Оценка), `replan` (Перепланировка), `deals` (Риелтор; раньше «Купля-продажа»). Любая кнопка
  с `data-contact="<направление>"` открывает окно записи с выбранным направлением; `/#contact` — сразу с окном.
- Заявка: `POST /api/lead` в `worker.js` → Telegram (`TG_TOKEN`, `TG_CHAT`, `TG_CHAT_<НАПРАВЛЕНИЕ>`).
  Без них воркер отвечает `{ ok: false }` (200), и сайт показывает кнопки «WhatsApp / Telegram / почта / позвонить» с готовым текстом.
  При PUT скрипта передавать `keep_bindings: ["secret_text", "plain_text"]`, иначе секреты сотрутся, и
  `compatibility_flags: ["assets_navigation_has_no_effect"]`, иначе браузер на «/» получит 404.html.
- Стиль — светлый и «воздушный» (по образцу data-pro.kz): цвета только через токены в `styles.css`,
  фирменный синий `--brand: #27449E` (с логотипа), шрифты Manrope (заголовки) и Onest (текст).
- Новые иконки — `<symbol id="i-…">` в спрайте в начале `index.html`.
- Шрифты Manrope и Onest (лицензия SIL OFL) лежат в `public/fonts/` и подключены через `@font-face` в начале `styles.css`:
  к серверам Google сайт не обращается, это указано в политике конфиденциальности. Cookie и аналитики нет — добавите, поправьте политику.
- Форма записи требует галочку согласия на обработку данных (`name=consent`), заявка без неё не отправляется; текст — в `privacy.html`.
- Фото — только с лицензией, разрешающей коммерческое использование; авторов дописывать в README.
- Кабинет администратора правит страницу по ключам `data-edit*` (тексты, списки, фото, меню; описание ключей — в начале
  `hoster/cms/render.php` и в README). Новые тексты размечать так же; в «простых» полях (без `data-edit-rich`) — никаких тегов;
  ключи не переименовывать и не удалять — по ним привязаны правки владельца. Правка из кабинета главнее текста в `index.html`:
  место, изменённое владельцем, правкой в коде не поменять. Контакты/специалисты/партнёры владелец может переопределить в
  кабинете (`window.SITE_OVERRIDES` поверх `site.config.js`). Перед пушем: `python3 tools/pack-hoster.py` и
  `php tools/cms-check.php <распакованный архив>`. PHP — совместимый с 7.0; не писать `?>` в комментариях PHP-файлов.
