# MEDIA Информ Плюс — сайт-визитка (подпроект в папке mip/)

Отдельный от «Табеля» и от `realty/` проект. Клиент — ТОО «MEDIA Информ Плюс» (МИП), Костанай и Рудный.
Бриф клиента — `content/brief.md` (тексты об оценке оттуда — ставить дословно, не переписывать).
Живой сайт: **https://mip-site.imakanovr.workers.dev** — Cloudflare Worker `mip-site` (аккаунт `3257b22ca5a38019c74864b01be83b81`).
Порядок выкладки — README («Выкладка»). Netlify не используется. `@view-transition` не включать (Chrome на хостинге его отменяет).

## Правила
- Чистые HTML/CSS/JS без сборки. Одна страница `public/index.html`, логика — `public/app.js` (ES-модуль).
- Контакты компании и трёх специалистов — только в `public/site.config.js`; в разметке телефоны/почта компании
  помечены `data-co-phone` / `data-co-email`, блоки специалистов — `data-spec="valuation|replan|deals"`.
- Направления: `valuation` (Оценка), `replan` (Перепланировка), `deals` (Купля-продажа). Любая кнопка
  с `data-contact="<направление>"` открывает окно записи с выбранным направлением; `index.html#contact` — сразу с окном.
- Заявка: `POST /api/lead` в `worker.js` → Telegram (`TG_TOKEN`, `TG_CHAT`, `TG_CHAT_<НАПРАВЛЕНИЕ>`).
  Без них воркер отвечает `{ ok: false }` (200), и сайт показывает кнопки «WhatsApp / Telegram / почта / позвонить» с готовым текстом.
  При PUT скрипта передавать `keep_bindings: ["secret_text", "plain_text"]`, иначе секреты сотрутся, и
  `compatibility_flags: ["assets_navigation_has_no_effect"]`, иначе браузер на «/» получит 404.html.
- Стиль — светлый и «воздушный» (по образцу data-pro.kz): цвета только через токены в `styles.css`,
  фирменный синий `--brand: #27449E` (с логотипа), шрифты Manrope (заголовки) и Onest (текст).
- Новые иконки — `<symbol id="i-…">` в спрайте в начале `index.html`.
- Фото — только с лицензией, разрешающей коммерческое использование; авторов дописывать в README.
